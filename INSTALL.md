# Install X Ambient

1. Download `x-ambient.zip` from this release and extract it.
2. In Chrome, open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder containing `manifest.json`.
4. Reload X, Twitch, or Kick. Open a post's details or hover over a timeline post or reply on X, or play a video or live stream on Twitch or Kick.

On X detail pages, the opened post lights up automatically. Hover over a reply to switch its colors into the background; leaving the reply returns to the opened post while its media is visible.

Use the extension's toolbar icon to adjust the lighting and language. **Language** follows Chrome automatically, or can be set to Español, English, or 日本語. **Fit X cards to window width** is off by default. Resetting lighting settings preserves the language choice.

To update an existing installation, replace the files in the same folder, click the extension's **Reload** button (↻), and reload X.

## Español

1. Extraé el ZIP de esta versión.
2. Abrí `chrome://extensions` y activá **Modo desarrollador**.
3. Elegí **Cargar descomprimida** y seleccioná la carpeta que contiene `manifest.json`.
4. Recargá X, Twitch o Kick. Abrí el detalle de una publicación de X o pasá el cursor sobre publicaciones y respuestas, o reproducí un video o un directo en Twitch o Kick.

En el detalle de X, la publicación abierta se ilumina automáticamente. Pasá el cursor sobre una respuesta para cambiar los colores; al salir, vuelve a la publicación abierta mientras su contenido esté visible.

Abrí el icono de la extensión para ajustar la iluminación. En **Idioma**, elegí **Español** o **English**, o dejá la detección automática. El ajuste del ancho de las tarjetas de X está desactivado inicialmente. Para actualizar, reemplazá los archivos en la misma carpeta, pulsá **Recargar** y recargá las páginas.

## 日本語

1. このReleaseの `x-ambient.zip` をダウンロードして解凍します。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で `manifest.json` があるフォルダを選びます。
4. X、Twitch、Kickを再読み込みします。Xの投稿詳細を開くか、タイムライン・返信にホバーするか、Twitch・Kickの動画や配信を再生してください。

Xの詳細では、開いたポストが自動で点灯します。返信へのホバーで色を切り替え、ホバーが外れると元のポストに戻ります。画面外のメディアは対象外です。

ツールバーの拡張アイコンから設定と言語を変更できます。ブラウザの言語を自動で使用するか、Español、English、日本語を選択できます。「Xのカードを画面幅に合わせる」は標準でOFFです。

更新時は同じフォルダに新しいファイルを置き、拡張管理画面の更新ボタン（↻）を押してXも再読み込みします。
